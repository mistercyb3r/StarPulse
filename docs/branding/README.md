# Branding

Official StarPulse visual identity for GitHub and the app.

| File | Use |
| --- | --- |
| `logo.svg` | Horizontal logo (icon + wordmark) |
| `logo.png` | PNG wordmark for README / docs |
| `icon.svg` | Square app mark |
| `icon-512.png` | High-res square mark |
| `github-social-preview.png` | GitHub repository social preview (1280×640) |

Regenerate PNG assets:

```bash
pip install pillow   # tooling only
python scripts/generate_branding.py
```
